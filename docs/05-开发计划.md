### 0.1 域名与备案的时序约束（**本计划唯一的行政硬期限**）

| 阶段 | 是否已有域名 | 合规状态 | 做法 |
|---|---|---|---|
| W1–W7 开发 | 不依赖 | 未上线，不对外提供服务 | 信令走 **`ws://114.55.114.12:8080`**，安全组**只放行两位开发者的出口 IP** |

> **两条原则**：
> ① **区分"技术依赖"与"法律义务"** —— 技术上 WSS 只依赖域名（TLS 证书），备案不阻塞代码开发；但**对公众提供服务**必须有备案。
> ② **开发期用 `ws://` 必须配安全组白名单**，绝不能让明文信令暴露在公网。

> **若要压到 9–10 周**：唯一有效手段是**给 A 加一个 Go 开发者**，把 Bridge（11–13 天）并出去，关键路径立即从 ≈45 天降到 ≈33 天。**已确认当前无 Go 资源，故按 12 周执行。**

## 4. 部署清单（`114.55.114.12`）

### 4.1 阿里云安全组（入方向）

| 端口 | 协议 | 用途 | 来源 |
|---|---|---|---|
| `443` | TCP | WSS（Caddy） | `0.0.0.0/0`（上线后） |
| `3478` | **UDP** | STUN / TURN | `0.0.0.0/0` |
| `3478` | **TCP** | TURN over TCP（UDP 被封的兜底） | `0.0.0.0/0` |
| `49160–49999` | **UDP** | TURN relay 段 | `0.0.0.0/0` |
| `8080` | TCP | **仅开发期**的明文信令 `ws://` | **仅两位开发者的出口 IP** |
| `22` | TCP | SSH | 仅管理 IP |

> 80/443 若尚未备案，对外网页访问会被阿里云拦截；**这不影响 TURN（3478/relay 走 UDP/TCP 非 80/443）**。

### 4.2 coturn 关键配置

```conf
listening-port=3478
fingerprint
lt-cred-mech
use-auth-secret
static-auth-secret=<S>
realm=<domain>
min-port=49160
max-port=49999
no-tls
no-cli
max-bps=6250000
bps-capacity=25000000
stale-nonce=1200
external-ip=114.55.114.12/<内网IP>
log-file=/var/log/turn
simple-log
```

**三条易错点**：
1. `external-ip` **必须显式配** —— 云主机是 NAT 环境，配错会让打洞与中继**同时全挂且不报错**；
2. **不设 `no-tcp`** —— 契约 `uris` 含 `turn:<host>:3478?transport=tcp`；`no-tls` 只关 5349，不影响 3478 的 TCP；
3. `user-quota` 若设置 **MUST ≥ 2** —— 两端拿到的是同一个 coturn 用户名（`username="<expire>:<pair_id>"`）。

### 4.3 Caddy 与 `ws://` → `wss://` 切换

```caddyfile
<domain> {
  encode zstd gzip
  reverse_proxy /v1/signal signal:8080
}
```

- **MUST NOT 配置 `trusted_proxies`**，除非 Caddy 前面真有可信代理；XFF 取**最右**；
- Signal 仅 compose 内网 `expose`，**不对公网**（否则"单 IP ≤16 限流"会退化为"全站 16 连接"）；
- 切换时机的判据：**域名已解析且 Caddy 已成功签发证书** → 改 QR 的 `s` 字段为 `wss://` 并把 `8080` 规则从安全组移除。

## 6. 贯穿项（每次 DSH 升级前后各跑一次）

1. **DSH 环境事实回归脚本** —— 固化 `../审查报告-四文档一致性与可行性.md` §1 的 24 条断言。其中以下 **7 条**是 DSH 升级后可能变的：
   - `isTrustedApiRequest` 只校验主机名 loopback（`/api` 围栏）
   - `ctx.webServer.port` 为真实监听端口、`.host` 为配置值
   - `ctx.connection.authenticatedUrl()` 可程序化取 token
   - token 交换须 `GET` + `pathname="/"` + 恰好一个 token 参 → **303 + Set-Cookie**
   - web profile `patchReload: live`
   - `FIBER_PENDING` 被 `assertEntriesActivated` 计为启动失败
   - `approval/request` 是 waterfall、服务名 `approval`
2. **E8 契约快照** —— `session/list|create|follow|prompt|cancel` 的端点与 **args 键名**；快照 JSON 入库，升级前后对比。
3. **E3 四条头部断言**（W1 顺手做，便宜且决定性）：改 Host 打 `/api*` → **403**；`GET /` → **401**；`/plugins/*` + dist 静态资源 → **200**。
