## 改了什么
- `cmd/signal/main.go`：入口（SIGNAL_PORT / TURN_SECRET 必填 / TURN_HOST）；`/v1/signal` + `/healthz`；sweeper；
- `internal/hub/hub.go`：内存态注册表（agents/phones/pairs/ptok/phoneIndex，02 §2 两个方向都要有）+ Notify 回调（按 id 解析当前连接投递）；
- `internal/hub/lifecycle.go`：pair 生命周期五条件全部主动推送；AttachAgent/AttachPhone 踢旧标记 stale（约束 1/2）；宽限期每次断开重新起算；销毁清 ptok（§4.4）；Bind 双向唯一性（条件④⑤）+ PAIR_LIMIT 不淘汰；OfferAllowed 自发 2s 限流（request 触发不受限）；Sweep 60s 判离线走同一条 GRACE 流程；
- `internal/hub/dispatch.go`：契约 §4 封闭集合 switch（未知 t → error+关闭）；hello 门禁按 02 §3.2 顺序（proto_ver → ts → nonce → 验签）；pair_id 断言失败 PAIR_NOT_FOUND+告警绝不跨 pair；sdp 字符串 ≤64KB 防放大；bye 过期代次忽略；
- `internal/hub/server.go`：WS 传输层（readLimit 64KB、10s hello 超时、单 IP ≤16 连接、IP 取 socket 对端——02 §5.1 心智模型）；
- `internal/auth/auth.go`：验签复用 `remotedsh-contract/go`（共享向量同源）；TURN 凭证 HMAC-SHA1（契约 §5）；
- `internal/limit/limit.go`：TokenGuard（5 次失败锁 10min）/ ConnCounter / RateState（20 msg/s/conn）；
- `internal/{auth,hub}` 测试 + `deploy/`（compose.yaml、Caddyfile、turnserver.conf、Dockerfile.signal、DEPLOY.md）+ README。
